# Parroċċa San Ġużepp – Msida

## Kif taġġorna l-avviżi

L-avviżi issa jiġu mill-fajl **avvizi.txt**. M'għandekx għalfejn tmiss `index.html`.

Kull ġimgħa:
1. Fuq GitHub iftaħ `avvizi.txt` u agħfas il-lapes (Edit).
2. Żid l-avviż il-ġdid **fuq nett**, qabel l-avviżi ta' qabel.
3. Uża dan il-format:

DATA: Il-Ħadd 6 ta' Settembru 2026
TITLU: Avviżi Parrokkjali
SOTTOTITLU: It-23 Ħadd ta' Matul is-Sena

Ikteb l-ewwel avviż hawn.

Ikteb avviż ieħor hawn. Ħalli linja vojta bejn avviż u ieħor.

---

4. **Tħassarx l-avviżi qodma.** Ħallihom taħt `---`; il-website tpoġġihom awtomatikament fl-Arkivju.
5. Agħfas **Commit changes**.

L-ewwel blokk fil-fajl dejjem jidher bħala l-aħħar avviż. Il-blokki l-oħra jidhru taħt **Arkivju tal-Avviżi**.
